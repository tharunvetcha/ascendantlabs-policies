# ascendantlabs-policies
Official privacy policies for Ascendant Labs apps, hosted publicly and maintained through GitHub Pages.

Each app gets its own folder, with an `index.html` (the canonical, linked-from-the-store-listing page) and a plain-text copy alongside it. Served via GitHub Pages (Settings → Pages → source: `main` branch, `/` root).
